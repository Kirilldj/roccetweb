# RoccetWeb — правила работы

## Концепция бренда
Премиальная цифровая студия. Глубокий чёрный фон, белая типографика,
электрические фиолетовые акценты, хромированные и Liquid Chrome 3D-элементы.
Минималистичная футуристическая эстетика, выразительная иерархия,
свободное пространство и аккуратная композиция.

## Обязательные правила
1. Не переделывать существующий дизайн.
2. Не переосмысливать визуальные решения самостоятельно.
3. Не заменять существующие секции и компоненты.
4. Не менять шрифты, цвета, отступы, пропорции и расположение элементов.
5. Не использовать типовые шаблоны сайтов агентств.
6. Не нарушать существующую функциональность.
7. Сохранять адаптивность.

## Порядок работы
1. Сначала анализ без изменения файлов, затем технический отчёт.
2. Задачи фиксируются в docs/TASKS.md.
3. Изменения вносятся только после явного подтверждения владельца.
4. Перед правкой указывать, какие файлы будут затронуты.
5. Каждое подтверждённое изменение записывается в docs/CHANGELOG.md.
